NPC Studio v3 · resource pack tool

Skin Pack Builder

Put your own skins on NPC Studio NPCs. Pick PNG skins for any of the 20 custom slots, name them, and download a small resource pack. Everything happens in this browser; nothing is uploaded.

How it works

  1. Pick skins for the slots below. Standard Minecraft skins: 64×64 PNG (128×128 HD also works).
  2. Name each one. The name and the skin's face show in NPC Studio's skin picker.
  3. Download the pack and open it with Minecraft. If your device saved it as .zip, rename it to .mcpack first.
  4. In your world: Settings → Resource Packs, activate it and move it above NPC Studio.
  5. In game: Spawn NPC → Custom skin slots. For Alex-style skins set Skin & Size → Arm Model → Slim.

Pack

Slots you leave empty keep NPC Studio's placeholder skin. Rebuild any time: NPCs remember their slot number, so updating the pack updates them.
