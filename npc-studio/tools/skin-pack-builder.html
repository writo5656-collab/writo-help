After downloading
  1. If the file saved as .zip, rename it to .mcpack.
  2. Open it: Minecraft imports the pack.
  3. World Settings → Resource Packs: activate it and move it above NPC Studio.
  4. Skins: Display → Skin, the Custom slots. Capes: Display → Cloak, after the 8 built-in ones. Models: Display → 3D model.

Questions

Do I need NPC Studio V3 installed?

Yes. This page only makes a skin pack; the NPCs come from the NPC Studio add-on on CurseForge.

My download is a .zip, not .mcpack

Rename the file so it ends in .mcpack, then open it. Minecraft imports it.

My skins don't show in game

In your world's Resource Packs, make sure the skin pack is active and sits above NPC Studio in the list.

Are my skins uploaded anywhere?

No. Your files stay on your device and the pack is built in your browser. Name search asks playerdb.co (Java) or GeyserMC (Bedrock) for that player's public skin.

Why can't it find a Bedrock player?

Microsoft doesn't publish Bedrock skins. GeyserMC only knows a skin after that player joined a Java server through Geyser. Ask them for the PNG instead.

Which models work?

Bedrock entity models from Blockbench: File → Export → Export Bedrock Geometry gives the .geo.json; also save its texture PNG. Name bones head, body, rightArm, leftArm, rightLeg and leftLeg to pose them. Position, turn and scale work on any model.

Can I add more skins later?

Yes. Build a new pack with all your skins and replace the old one. NPCs keep their slot numbers.
