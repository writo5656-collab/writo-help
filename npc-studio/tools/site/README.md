## ✨ What it does

| | |
|---|---|
| 🧍 **Live 3D preview** | See every skin on a walking Minecraft character before you build. Drag to turn it. |
| 📥 **Drop up to 20 skins** | Drag and drop them all at once; they fill the 20 custom slots in order. |
| 🏷️ **Names & faces** | Name each skin. Its name and face show up in NPC Studio's skin picker. |
| 💪 **Classic or slim** | Preview Steve (4px) or Alex (3px) arms. |
| 📦 **One-tap pack** | Downloads a ready-to-import `.mcpack`. Tap it and Minecraft opens it. |
| 🔒 **Private** | Everything runs in your browser. Nothing is uploaded anywhere. |

## 🚀 How to use it

1. **Open the builder** → **https://noxeelmc-art.github.io/npc-studio-skins/**
2. **Drop in your skins** (64×64 or 128×128 PNG) and give each one a name.
3. **Download the pack** and open it — Minecraft imports it.
4. In your world: **Settings → Resource Packs** → activate the pack and move it **above** NPC Studio.
5. In game: **Spawn NPC → Custom skin slots.** For Alex-style skins set **Skin & Size → Arm Model → Slim**.

> 💡 Got a `.zip` instead of `.mcpack`? Rename it so it ends in `.mcpack`, then open it.

## ❓ FAQ

<details><summary><b>Do I need NPC Studio V2?</b></summary>
Yes. This page only makes the skin pack; the NPCs come from the NPC Studio V2 add-on.
</details>
<details><summary><b>My skins don't show in game</b></summary>
Make sure the skin pack is active and sits <b>above</b> NPC Studio in your world's Resource Packs.
</details>
<details><summary><b>Can I add more skins later?</b></summary>
Yes — build a new pack with all your skins and replace the old one. NPCs keep their slot numbers.
</details>
