NPC Studio editor, redesigned

A Java-style workbench for Bedrock: sections you can fold, NPC heads on the right, tools at the bottom and a thin outline you can resize. Drag the world to look around. On a phone, turn it sideways.

What this means for the add-on

The panel is a menu

Bedrock only takes taps inside menus. So the panel, the NPC list and the bottom tools all live in one full-screen menu, with the world showing through the middle. Close it (X or back) to walk; your hotbar is the toolbar then.

Folding sections

Each section header is a button. Tapping it reopens the menu with that section folded, without any animation, so it feels instant.

Sliders, number boxes, text

Two options: this look with an Apply button, or Mojang's grey live editor where the NPC moves while you drag. Pick per section; Transform and Pose suit live dragging.

Thin outline

The Java outline is a slightly bigger copy of the NPC drawn only from behind. Bedrock needs a custom material for that, which I'd test first. Thickness comes in thin, medium and thick.

Live camera preview

No add-on can draw a second view on screen. The Preview Viewer item switches your whole screen to Camera 1 (tap for the next one) and back.

Only two items

Director's Baton opens the editor (tap an NPC to edit it). Preview Viewer looks through cameras. The other tools move into the editor's bottom bar and tabs.
